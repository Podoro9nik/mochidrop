# Иконка MochiDrop — «Моти-курьер»

Мягкий маскот с кошачьими ушками и крупной стрелкой вниз связывает кавайный характер приложения с загрузкой аниме и манги. Скруглённая сиреневая плитка сохраняет узнаваемый силуэт в Dock, панели задач и списке приложений.

## Какой файл использовать

| Файл | Назначение |
| --- | --- |
| `icon-master.svg` | Векторный оригинал для редактирования и экспорта крупных размеров. |
| `icon-small.svg` | Версия для 16–32 px: детали лица и стрелки немного толще, чтобы сохранять читаемость. |
| `icon-1024.png` | Основной растровый оригинал 1024 × 1024 px с прозрачным полем вокруг плитки. |
| `png/icon-{size}.png` | Готовые PNG нужного размера для интерфейса и документации. |
| `macos/MochiDrop.iconset/` | Набор PNG для macOS; AppIcon в `Assets.xcassets` подключает иконку к приложению. Отдельный `MochiDrop.icns` создаётся в macOS CI. |
| `windows/MochiDrop.ico` | Многоразмерная иконка для ресурсов Windows-приложения и установщика. Содержит 16, 20, 24, 32, 40, 48, 64, 96, 128 и 256 px. |

Windows ICO — ассет для Windows-проекта. Сам код приложения на SwiftUI предназначен для macOS; наличие ICO не создаёт Windows-сборку приложения.

## Палитра

| Цвет | Роль |
| --- | --- |
| `#C9AFE8` → `#9B79C9` | Вертикальный градиент плитки: светлая сирень сверху, более насыщенная снизу. |
| `#FFF8F3` | Молочный силуэт маскота. |
| `#62477F` | Тёмно-сиреневые глаза. |
| `#E875AB` | Клубнично-розовая стрелка загрузки — главный функциональный акцент. |

В оригинале также используются полупрозрачные тени: `#3F285C` под плиткой и `#76529E` под маскотом. Сохраняйте их прозрачность при экспорте.

## Масштаб и свободное поле

Масштабируйте иконку пропорционально целиком. Не растягивайте, не обрезайте прозрачное поле и не увеличивайте маскота отдельно от плитки. Встроенные отступы защищают скругления и тень; при размещении в собственном макете оставляйте снаружи ещё не менее 5% ширины иконки до соседнего текста или графики.

Для 16–32 px используйте маленькую версию и соответствующие готовые PNG или слой ICO. Для размеров от 40 px используйте основной оригинал. Не добавляйте мелкие украшения, текст или дополнительную рамку. На светлом и тёмном фоне сохраняйте утверждённую цветную плитку.

Размеры платформенных наборов основаны на документации [Apple Icon Set Type](https://developer.apple.com/library/archive/documentation/Xcode/Reference/xcode_ref-Asset_Catalog_Format/IconSetType.html) и [Microsoft About Icons](https://learn.microsoft.com/en-us/windows/win32/menurc/about-icons).
