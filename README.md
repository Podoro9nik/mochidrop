# MochiDrop для macOS

Нативное приложение на SwiftUI для macOS 15 и новее. Интерфейс и очередь загрузок написаны на Swift; торрент-загрузчик — отдельный встроенный исполняемый файл на Rust. Tauri и WebView в этом проекте нет.

## Возможности

- Поиск по названию прямо в AniLiberty, Nyaa, Tokyo Toshokan и MangaDex.
- Кнопка **«Скачать»** у результата сразу добавляет его в очередь.
- Magnet, URL или локальный файл `.torrent`; скачивание внутри приложения через `librqbit`.
- Загрузка страниц видео через встроенный `yt-dlp`, глав манги через `gallery-dl` с созданием CBZ.
- Прямые HTTP(S) ссылки на видео, а также список HTTPS ссылок на изображения главы.
- Две параллельные загрузки, пауза, продолжение, история, выбор папки и быстрые клавиши.

Поддержка конкретного сайта зависит от его текущего API, доступности и правил. Некоторые источники требуют аккаунт; DRM приложение не обходит.

## Автоматическая сборка

В корне репозитория находится [`.github/workflows/macos-build.yml`](.github/workflows/macos-build.yml). **Каждый push** запускает сборку на GitHub Actions отдельно для Apple Silicon и Intel. Runner устанавливает XcodeGen, создаёт Xcode-проект из [`project.yml`](project.yml), находит проект и схему, собирает Release-приложение и добавляет встроенные загрузчики. После упаковки runner запускает приложение и проверяет, что главное окно стало видимым и процесс продолжает работать. Если снимок экрана доступен, он сохраняется как отдельный артефакт `macOS-gui-smoke-<архитектура>`.

Для каждой архитектуры в Actions появляется артефакт `macOS-build-arm64` или `macOS-build-x86_64`, содержащий:

- `MochiDrop.app`;
- `MochiDrop-macOS-<архитектура>.zip`;
- `MochiDrop-macOS-<архитектура>.dmg`.

Для установки используйте ZIP или DMG: загрузка отдельной папки `.app` из интерфейса GitHub может не сохранить разрешения исполняемых файлов. ZIP создаётся macOS-командой `ditto`, DMG — `hdiutil`.

Переменные репозитория `MACOS_XCODE_CONTAINER`, `MACOS_SCHEME` и `MACOS_APP_NAME` позволяют переопределить автоматически найденный проект, схему и имя приложения.

## Локальная разработка на Windows

SwiftUI и Xcode локально на Windows не собираются. Исходники можно редактировать здесь; сборка, проверка запуска и упаковка выполняются только в GitHub Actions на macOS. Исходники опубликованы в [репозитории](https://github.com/Podoro9nik/mochidrop); статус и файлы находятся во вкладке **Actions** соответствующего запуска.

## Подпись

Xcode собирает приложение без сертификата, затем workflow ставит локальную подпись ad hoc для проверки и личного использования. На другом Mac Gatekeeper может потребовать вручную разрешить запуск. Для обычного публичного распространения нужен сертификат Apple Developer ID и нотариализация; секреты подписи нельзя записывать в исходники или workflow.

Лицензии встроенных `yt-dlp`, `gallery-dl` и `librqbit` лежат в `third_party/` и добавляются в пакет. Rust-зависимости фиксируются в `TorrentHelper/Cargo.lock`.
